# 2D and 3D scenes

Build 3D scenes from meshes, cameras and transforms, then show them flat, lit or path traced.

## Build a 3D entity

| Component | What it holds |
| --- | --- |
| `Transform3D` | Position, rotation in radians, scale |
| `Mesh3D` | A shared mesh and its base color |
| `Camera3D` | A perspective camera (Y up) |
| `SurfaceEmission` | Optional HDR emission for path tracing and 3D radiance cascades |

The following example shows a red cube in front of a camera:

```csharp
int cube = ECS.CreateEntity(new Vector3(0, 0.5f, 0));
ECS.AddComponent<Mesh3D>(cube) = new Mesh3D { Geometry = cubeMesh, Color = new Color(200, 40, 40) };

int camera = ECS.CreateEntity();
ECS.AddComponent<Camera3D>(camera) = new Camera3D { Position = new Vector3(0, 2, 6), Target = Vector3.Zero };
```

Build meshes from vertices and indices; see [meshes](Math.md#meshes). One mesh can be shared by any number of
entities.

## Show it on screen

A 3D view is a short chain of systems: collect the meshes, rasterize them, choose a look, present.

The following example shows the smallest 3D pipeline:

```csharp
var meshes = ECS.AddSystem<MeshGeometry3D>();
var geometry = ECS.AddSystem(new Geometry3D { Source = meshes, After = [meshes] });
var flat = ECS.AddSystem(new FlatRenderer { Input = geometry.GetOutput, After = [geometry] });
ECS.AddSystem(new RenderPresenter { Input = flat.GetOutput, After = [flat] });
```

Choose lit raster, path tracing or experimental 3D radiance cascades, and add tone
mapping and antialiasing; see [rendering pipelines](Rendering.md). Path tracing
and radiance cascades consume `MeshGeometry3D` directly instead of rasterizing
through `Geometry3D`.

In the Cornell demo, select **Radiance cascades** in the renderer selector to use
diffuse probe lighting with UDR4 Balanced. The demo starts that mode with 16³
probes; adjust lighting under **F1 → View → Radiance cascades** and reconstruction
under **F1 → View → Image quality**. See
[Global illumination](HRC.md#3d-radiance-cascades) for setup and material limits.

The following example shows how to launch that configuration from the engine
repository root:

```sh
dotnet run --project tests/Radiant.3D -c Release -- --radiance-cascades
```

## Drive cameras with transforms

Give a camera entity a `Transform3D` and the transform positions and rotates it, while `Camera3D` keeps the lens
(field of view, clip range). Without a transform, the camera's `Position`, `Target` and `Up` decide where it
looks. The same works in 2D with `Camera2D` and `Transform2D`.

Fly any camera live with the [camera controls](CameraControls.md).

## Ask for extra buffers

`Geometry3D` produces color by default. Request normals and depth when another stage needs them, such as TAA or
the buffer inspector.

```csharp
var geometry = ECS.AddSystem(new Geometry3D { Source = meshes, Channels = GeometryChannels.All, After = [meshes] });
```

| Buffer | Contents |
| --- | --- |
| Color | Unlit base color, transparent background |
| Normals | World normals encoded as `normal * 0.5 + 0.5` |
| Depth | Linear depth divided by the camera's far plane |

## Render thin surfaces

Closed meshes hide their back faces. For leaves, paper or open boxes, set `DoubleSided = true` on the `Mesh3D` so
both sides render.

## Edit the scene live

Open **F1 → ECS → Open Entity Inspector**, pick an entity and edit any public field (positions, colors, lens
settings) while the scene runs. Every renderer updates immediately. Edits are not saved to your source files.
